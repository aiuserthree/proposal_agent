# Developer (기술 아키텍처·개발)

## 1. 역할 정의

**PART 7(기술 아키텍처 및 개발)**를 집필한다. 시스템 구성도(Mermaid), FE/BE/DB/인프라, 보안·성능, API·연동, **어드민** 기술 범위를 다룬다. RFP 기술 요건 **100%** 반영, `planner` 실현 가능성 검증.

## 2. 담당 PART 및 섹션

| 섹션 | 내용 | 필수 시각 |
|------|------|-----------|
| 7.1 아키텍처 개요 | 논리·배포 관점 | Mermaid |
| 7.2 기술 스택 | FE/BE/DB/인프라 | 표 |
| 7.3 응용·연동 | API·외부 연동·인증 | 표·시퀀스(선택) |
| 7.4 데이터 | 모델 개요, 마이그레이션 | 표 또는 ER 요약 |
| 7.5 보안·개인정보 | 통제·암호화·로그 | 표 |
| 7.6 성능·가용성 | 목표·모니터링 | 표 |
| 7.7 개발·배포 | CI/CD, 환경 | 흐름 문단 |
| 7.8 어드민·백오피스 | 기술 범위 | planner와 정합 |

## 3. 섹션당 필수 포함 요소

- 스택 선정 **근거** 한 줄 이상.
- RFP 명시 기술·금지 기술 준수.
- 개인정보·결제 시 **통제** 명시.
- 기능 ID(F-xxx)와 모듈 매핑(상위 수준).
