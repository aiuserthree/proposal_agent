# RFP: 코스모 화장품 공식 온라인몰 리뉴얼 구축

## 1. 사업 개요
- 사업명: 코스모 화장품 공식 온라인몰 리뉴얼
- 발주기관: (주)코스모 화장품
- 사업기간: 2026년 5월 ~ 2026년 10월 (6개월)
- 사업예산: 3억 원 (부가세 별도)
- 프로젝트 유형: A (웹 리뉴얼) + B (모바일 앱)

## 2. 사업 배경
코스모 화장품은 2018년 온라인몰을 오픈하여 운영 중이나, 현재 사이트는 노후화되어 모바일 이탈률이 67%에 달하고 있습니다. 경쟁사 대비 UX가 뒤처지며, MZ세대 고객 확보에 어려움을 겪고 있습니다. 이에 PC/모바일 웹 전면 리뉴얼 및 네이티브 앱 신규 구축을 추진합니다.

## 3. 사업 목적
- 모바일 중심 쇼핑 경험 혁신
- MZ세대 타겟 브랜드 이미지 강화
- 온라인 매출 전년 대비 40% 증대
- 재구매율 현재 22%에서 35%로 향상

## 4. 주요 과업 범위

### 4.1 PC/모바일 웹 리뉴얼
- 반응형 웹 설계 (PC, 태블릿, 모바일)
- 메인 페이지 개편
- 상품 목록/상세 페이지 리뉴얼
- 장바구니/결제 프로세스 개선
- 마이페이지 리뉴얼
- 브랜드 스토리 페이지 신규
- 성분 사전 페이지 신규
- 뷰티 매거진/콘텐츠 허브

### 4.2 모바일 앱 신규 구축
- iOS/Android 네이티브 앱
- 푸시 알림 (프로모션, 재입고, 배송)
- 앱 전용 혜택/쿠폰
- AR 가상 메이크업 체험 기능
- 피부 진단 테스트 기능

### 4.3 회원/CRM
- 소셜 로그인 (카카오, 네이버, 애플)
- 멤버십 등급 시스템 (4단계)
- 포인트 적립/사용
- 생일/기념일 자동 쿠폰 발급
- 개인화 상품 추천

### 4.4 상품/주문 관리
- 상품 등록/수정 (대량 업로드)
- 옵션/세트 상품 관리
- 주문/결제/교환/반품 처리
- PG 연동 (카드, 간편결제, 계좌이체)
- 재고 관리 및 알림

### 4.5 관리자 시스템
- 대시보드 (매출, 주문, 회원 현황)
- 상품 관리
- 주문/배송 관리
- 회원/등급 관리
- 프로모션/쿠폰 관리
- 콘텐츠(매거진) 관리
- 통계/리포트 (일별/주별/월별)
- 권한 관리 (역할별)

### 4.6 연동
- ERP 연동 (재고/주문 동기화)
- CJ대한통운 배송 API 연동
- 카카오 알림톡/친구톡 연동
- Google Analytics 4 + Meta Pixel 연동

## 5. 기술 요건
- 프론트엔드: 반응형 웹 필수, SPA 권장
- 백엔드: RESTful API 기반
- 모바일: 네이티브 또는 크로스플랫폼
- DB: 관계형 DB 필수
- 클라우드: AWS 또는 NCP 기반
- 보안: SSL, 개인정보 암호화, PCI-DSS 준수
- 성능: 동시접속 3,000명, 페이지 로딩 2초 이내

## 6. 디자인 요건
- 코스모 CI/BI 반영 (메인컬러: #E8567F, 서브컬러: #2D2D2D)
- 클린/미니멀 디자인 톤
- 뷰티 브랜드 감성 반영
- 웹 접근성 AA 등급 준수
- 메인 페이지 시안 2종 이상 제출
